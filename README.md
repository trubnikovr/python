# Internet download speed

Консольный скрипт выполняет 10 последовательных HTTP(S)-запросов к указанному адресу, полностью считывает каждый ответ и обновляет строку прогресса после каждого запроса. Зависимости не нужны: достаточно Python 3.8 или новее.

## Запуск

```bash
python3 main.py 'https://example.com/large-file.jpg'
```

Укажите адрес доступного ресурса, желательно достаточно большого для измерения. Скрипт выводит среднее время запроса в секундах, общий объём тел ответов в байтах и скорость в **Мбит/с** (1 Мбит = 1 000 000 бит). Скорость вычисляется как общий объём, умноженный на 8 и разделённый на суммарное время запросов. Время включает установку соединения, возможные перенаправления и получение ответа целиком.

Результат зависит от сервера, сети и кэширования и не обязательно равен максимальной скорости интернет-соединения. При ошибке любого запроса скрипт завершится с ненулевым кодом, не выводя неполный результат. Тайм-аут сетевых операций — 30 секунд.
